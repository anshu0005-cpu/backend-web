# Student Management REST API

## Run
npm install
npm start

Server: http://localhost:3000

## APIs
GET /students
GET /students/:id
POST /students
PUT /students/:id
DELETE /students/:id

POST/PUT JSON:
{"name":"Priya","age":19,"course":"BSc Computer Science","email":"priya@example.com"}

Status codes: 200 Success, 201 Created, 400 Bad Request, 404 Not Found.
